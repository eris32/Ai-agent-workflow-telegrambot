# n8n Telegram VPN Subscription Automation

Automated Telegram bot workflow built with n8n, Hiddify API,
subscription management, payment processing, database storage,
and automatic user provisioning.

## Features

- Telegram Bot Trigger
- Command routing with Switch
- Hiddify API integration
- User creation / status / deletion
- Subscription plans
- Payment gateway integration
- Payment Webhook verification
- Automatic VPN user provisioning
- Order and subscription database
- Telegram payment confirmation
- Automated user access delivery
